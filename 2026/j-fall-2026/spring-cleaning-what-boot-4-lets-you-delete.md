# Spring Cleaning: What Boot 4 Lets You Delete

**Format:** Session

## Abstract

It is now more important than ever to stay up to date and patched on open source software. If you are upgrading to Spring Boot 4 there's a decent chance you're maintaining three or four things that are now unnecessary, and nobody on your team told you.

This is a tour of the release disguised as a demolition. Built-in resilience, so Spring Retry goes. HTTP interface clients, so Feign goes. First-class API versioning, so that filter someone wrote in 2021 goes. RestTestClient, so a pile of test scaffolding goes. Along the way we'll hit the additions you can't delete your way into: JSpecify null safety, Jackson 3, modular auto-configuration and the features it quietly turns off, plus the smaller changes that are easy to miss and quietly useful.

You'll leave with fewer dependencies to patch, less code to maintain, and a working plan for the upgrade.
