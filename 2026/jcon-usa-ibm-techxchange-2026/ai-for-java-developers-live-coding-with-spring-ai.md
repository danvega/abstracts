# AI for Java Developers: Live Coding with Spring AI

**Format:** Session

## Abstract

You don't need Python to build AI applications. The JVM has everything you need, and for enterprise development it's arguably better positioned than any other ecosystem. Your existing Spring skills carry over.

This is a live coding session. No slides, just an IDE and a Spring Boot app that gets smarter as we go. Spring AI gives you one API across OpenAI, Anthropic, and local models, so nothing you build is locked to a provider. We'll turn LLM responses into typed Java objects, then give the model access to live data and let it trigger actions in your app with tool calling.

You'll leave with a repo of working code and a clear path to adding AI features to the applications you already have.
