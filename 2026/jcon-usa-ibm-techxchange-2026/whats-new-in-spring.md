# What's new in Spring

**Format:** Session

## Abstract

If you're upgrading to Spring Boot 4, there's a decent chance you're maintaining three or four things that are now unnecessary, and nobody told you.

This is a tour of the release disguised as a demolition. Built-in resilience, so Spring Retry goes. HTTP interface clients, so Feign goes. First-class API versioning, so that filter someone wrote in 2021 goes. RestTestClient, so a pile of test scaffolding goes. Along the way we'll hit the changes you can't delete your way into: JSpecify null safety, Jackson 3, and modular auto-configuration and what it quietly turns off.

You'll leave with fewer dependencies to patch, less code to maintain, and a plan for the upgrade.
