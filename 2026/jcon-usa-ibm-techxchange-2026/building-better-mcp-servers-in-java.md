# Building Better MCP Servers in Java

**Format:** Session

## Abstract

Building an MCP server is easy. Building one that is useful, secure, and easy for a model to understand is much harder.

We'll start with a quick intro to the Model Context Protocol: what an MCP server is, what it is not, and when to reach for MCP instead of a skill, a normal API, or a direct integration. Then we'll build one in Java with Spring AI and connect it to real clients like Claude and your IDE. From there, the interesting part: what separates a good MCP server from a working one. Tool names and descriptions, parameter design, response size, progressive tool discovery, and securing access to your server and its tools.

You'll leave knowing how to build, design, and secure an MCP server in Java.
