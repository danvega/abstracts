# AI for Java Developers

## Abstract

AI has become an unavoidable topic in software development, and many Java developers are wondering if they need to learn Python to participate. The answer is no. The Java ecosystem has everything you need to build modern AI applications, and your existing skills carry over more than you might think.

Spring AI brings generative AI to Java developers using the Spring programming model you already know. In this session, we'll look at what's possible today, all built on the JVM. We'll cover model abstraction, so you can write code once and run it against OpenAI, Anthropic, or a local model on your laptop. Prompt templates for cleaner, reusable prompts. Structured output that turns LLM responses into typed Java objects you can actually use. Tool calling that lets the model fetch live data and trigger actions in your application. And the Model Context Protocol, the emerging standard for connecting AI to your tools and data.

You'll leave knowing exactly where Spring AI fits in your stack, and how to start adding intelligent features to applications you already have.
