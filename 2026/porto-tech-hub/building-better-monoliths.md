# Building Better Monoliths with Spring Modulith

## Abstract

Most teams jump straight from a big ball of mud to microservices. The modular monolith is a better starting place, and for most applications, it's where you should stay.

Spring Modulith makes the modular monolith a first class citizen in Spring Boot. Clear boundaries. Enforced at compile time. Modules that talk through events, with a transactional outbox you get for free. One test fails the build the moment someone sneaks an import they shouldn't.

In this session, we'll cover what a modular monolith really is. Why it's the right answer for most Spring Boot applications most of the time. And how Modulith turns your existing package structure into real modules. No new build tooling. No new framework to learn. We'll close with a live walkthrough of a real Spring Boot app, so you can see what these ideas look like in code you'd actually ship.

You'll leave with a clear mental model and a concrete first step you can apply to your own codebase.
