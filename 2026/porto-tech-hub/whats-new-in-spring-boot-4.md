# What's new in Spring Boot 4

## Abstract

Spring Boot 4 is here, and it brings the biggest set of changes the framework has seen in years. Better performance. Cleaner developer workflows. Production ready features built in instead of bolted on.

This session is a practical tour of what's new. We'll cover HTTP interfaces, the declarative way to call other services without writing boilerplate. JSpecify, which finally brings real null safety to your Spring code. Jackson 3, with everything that means for your APIs. And the resilience patterns that ship in the box, so your applications can handle real world failure.

If you're starting a new project, you'll know exactly which features to reach for. If you're upgrading from Spring Boot 3, you'll know what's improved, what's changed, and what to watch out for before you bump that version number in production.

You'll leave ready to build with Spring Boot 4, and confident you can bring your existing applications along with you.
