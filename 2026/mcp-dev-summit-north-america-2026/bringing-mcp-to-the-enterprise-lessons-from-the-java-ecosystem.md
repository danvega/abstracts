# Bringing MCP to the Enterprise: Lessons from the Java Ecosystem

**Format:** Session

## Abstract

How are developers connecting LLMs to their data and tools? In the enterprise, the answer looks different than you might expect. Fortune 500 companies aren't abandoning their infrastructure or reskilling their teams. They're running millions of lines of Java on Spring, and that's not changing.

This session shares what we've learned bringing MCP to the Java ecosystem. The Spring AI team contributed to the official MCP Java SDK and built Spring Boot support on top of it. We'll cover design decisions that matter for the enterprise: type safety, familiar programming models, and patterns that fit into existing architectures.

You'll learn how to build MCP integrations with Spring Boot and just how little code it takes. Spring's abstractions handle the protocol complexity, letting you focus on what matters: connecting your enterprise data and systems to AI. Finally, we'll cover lessons learned and the questions enterprises need to answer around security, governance, and observability.

Whether you're building MCP infrastructure or driving adoption in your organization, this session offers the perspective of the largest developer community in the enterprise.
