# Spring AI in Practice: A Hands-On Workshop for Java Developers

**Format:** Workshop

## Abstract

Building an AI demo is easy. Understanding the patterns behind a real AI application is harder. In this workshop, we'll live code our way through the core capabilities of Spring AI, building each feature from scratch and seeing how it fits into a modern Java application.

Bring a laptop with Java and your IDE of choice. You'll spend four hours writing code alongside me, working through the core features of Spring AI with hands-on examples you can take home and continue exploring.

We'll tackle one capability at a time. We'll start with Spring AI's model abstraction and see how the same code can work with OpenAI, Anthropic, or a local model with minimal configuration changes. Then we'll use prompt templates to create reusable prompts and structured output to turn LLM responses into typed Java objects. From there, we'll add tool calling so models can access live data and invoke Java code. We'll finish with the Model Context Protocol by building an MCP server and exposing capabilities to MCP-compatible AI clients.

You don't need any prior AI experience. Just comfort with Spring Boot and a willingness to write code alongside the room. You'll leave with the complete workshop repository, a clear mental model of how these capabilities fit together, and practical examples you can use in your own projects.
