# Spring AI in Practice: A Hands-On Workshop for Java Developers

**Format:** Workshop

## Abstract

Building an AI demo is easy. Understanding the patterns behind a real AI application is harder. In this workshop, we'll live code our way through the core capabilities of Spring AI, building features from scratch and seeing how they fit into a modern Java application.

Bring a laptop with Java and your IDE of choice. You'll spend two hours writing code alongside me, working through practical examples you can take home and continue exploring.

We'll start with Spring AI's model abstraction and see how Java applications can work with different AI models through a consistent API. From there, we'll explore structured output, tool calling, and context engineering: how to give a model the right instructions, data, and capabilities at the right time without overwhelming the conversation.

Along the way, we'll focus on the patterns that matter when moving beyond a simple chat demo and building AI features into real applications.

You don't need any prior AI experience. Just comfort with Spring Boot and a willingness to write code alongside the room. You'll leave with the complete workshop repository, a clear mental model for building AI applications with Spring AI, and practical examples you can continue experimenting with after the workshop.
