# Coding Agents: Start Simple, Scale Smart

**Format:** Session

## Abstract

Coding agents change every week. New commands, new features, and someone on your timeline saying they automated their whole job from the gym. If you feel behind, you're not. Nobody uses all of it, and you don't need to.

What you need are the building blocks, in the right order. We'll use Claude Code for the live demos, but the patterns work with any coding agent. We start with how an agent loop actually works, what it costs you in tokens and context, and how to use these tools safely with permissions.

Then we look at context and memory, including project instructions that make every future session better. Once the basics are in place, we scale up: reusable skills, external tools with MCP, subagents, hooks, and longer-running work you can hand off.

The whole time, we'll be honest about where agents save real time and where they add risk. You'll leave knowing what to learn first, what to add as your needs grow, and what you can safely ignore until you need it.

Start simple. Scale smart.
