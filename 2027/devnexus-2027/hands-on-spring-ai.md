# Hands on Spring AI

**Format:** Workshop

## Abstract

If you've never used Spring AI, this workshop is for you.

We'll spend the day working through the features of Spring AI, one at a time. For each one, you'll learn what it does and when to reach for it. Then you'll write a small demo of it yourself. This is very hands-on. You'll be coding for most of the day.

We start with what you need to get going:

- Setting up a project and talking to a model with ChatClient
- Switching between OpenAI, Anthropic, and a local model
- Prompts, prompt templates, and chat memory
- Structured output that turns responses into Java records

Then we move into the features real apps are built on:

- Advisors, and how they shape every request and response
- Tool calling, so the model can call your Java code
- Retrieval augmented generation (RAG) with your own documents
- MCP, from building servers to connecting clients
- Agents that plan and act on their own

By the end of the day, you'll have a folder full of working demos, a clear picture of how the parts of Spring AI fit together, and everything you need to build your first AI app on your own.

You should be comfortable with Java and Spring Boot. You don't need any AI experience.

Setup: Java 21 or later, an IDE, and Docker. Setup instructions go out before the workshop.
