# Spring AI in Practice: A Hands-On Workshop for Java Developers

**Format:** Workshop

## Abstract

Building an AI demo is easy. Understanding the patterns behind a real AI application is harder. In this workshop, we'll live code our way through the core capabilities of Spring AI, building each feature from scratch and seeing how it fits into a modern Java application.

Bring a laptop with Java and your IDE of choice. You'll spend the workshop writing code alongside me, working through practical examples you can take home and continue exploring.

We'll start with Spring AI's model abstraction and see how the same application can work with OpenAI, Anthropic, or a local model with minimal configuration changes. From there, we'll explore prompts and structured output, turning model responses into typed Java objects your application can actually use.

Then we'll move beyond simple prompts and look at context engineering: how to give a model the right instructions, data, conversation history, and capabilities at the right time. We'll use tool calling to connect models to Java code and live data, and explore the patterns that help AI applications become more useful, reliable, and maintainable.

Along the way, we'll build each capability into the same application so you can see how the pieces fit together rather than treating them as isolated demos.

You don't need any prior AI experience. Just comfort with Spring Boot and a willingness to write code alongside the room. You'll leave with the complete workshop repository, a clear mental model for building AI applications with Spring AI, and practical examples you can continue experimenting with after the workshop.
